# Prompts de IA para la rama Mayuri

## Prompt base
Actúa como desarrollador senior en Python + Streamlit.
Estoy trabajando en la rama Mayuri del repositorio las-COBRAS.
Necesito mejorar la experiencia de adopción responsable de mascotas.
Contexto:
- la app ya tiene algunas pantallas funcionales,
- necesito mejorar la experiencia de usuario,
- quiero mantener la estructura actual de la aplicación,
- usar Python + Streamlit,
- mantener orden y claridad,
- priorizar mejoras útiles y simples.

Necesito:
1. revisar el archivo afectado,
2. analizar el problema,
3. proponer una solución concreta,
4. mantener la estructura del proyecto,
5. entregar código limpio y útil,
6. explicar brevemente por qué es una mejora buena.

## Prompt para flujo principal
Revisa la experiencia de adopción general.
Necesito mejorar la claridad del recorrido del usuario desde que entra a la app hasta solicitar una mascota.
No quiero una solución compleja, sino una mejora útil, clara y profesional.

## Prompt para pantalla de inicio
Revisa la pantalla de inicio de la app.
Necesito:
- mejorar jerarquía visual,
- resaltar el flujo de adopción,
- guiar mejor la acción del usuario,
- mantener el estilo actual y mejorar el diseño sin romper la app.

## Prompt para catálogo
Revisa la pantalla del catálogo.
Necesito:
- mejorar legibilidad,
- mejorar filtros,
- mejorar presentación visual de las mascotas,
- mantener lógica ya existente.

## Prompt para compatibilidad

Necesito:
