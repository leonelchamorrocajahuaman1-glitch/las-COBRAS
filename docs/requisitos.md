# Requisitos del proyecto

## Objetivo
Crear una plataforma para adopción responsable de mascotas.

## Usuarios
- adoptante
- administrador del refugio

## Requisitos funcionales
- ver catálogo de mascotas
- filtrar por especie y tamaño
- test de compatibilidad
- enviar solicitud
- consultar estado
- panel administrativo

## Requisitos no funcionales
- seguridad
- fácil uso
- diseño claro
- rendimiento aceptable

## Prioridad
P0:
- flujo principal
- catálogo
- compatibilidad
- solicitud
- seguimiento
- panel admin

P1:
- historias de adopción
- personaje guía
- match cards

P2:
- sonidos
- animaciones
